# scripts/

This directory is reserved for the future NeoMundi AI Weather launcher.

Nothing here is wired up yet. This is a placeholder so the repository
structure already reflects the intended automation pipeline:

```text
launcher (this directory)
   ↓
query AI providers (per config/panel.yml)
   ↓
raw observations
   ↓
NeoMundi measurement
   ↓
aggregation
   ↓
weather.json  +  data/current.json  +  data/history/<date>.json
   ↓
GitHub Pages refresh (index.html, widget.html)
```

## What the launcher will need to do

1. Read `config/panel.yml` to get the enabled systems and protocol
   parameters (`iterations`, `prompt_set`, etc.).
2. Run the sentinel prompt(s) against each enabled system the configured
   number of times.
3. Send the raw observations through NeoMundi's measurement layer.
4. Aggregate the results into the schema currently produced manually in
   `weather.json` (see the root `weather.json` for the exact shape:
   `protocol`, `global_condition`, `panel_summary`, `systems[]`).
5. Write the result to `weather.json` (served at the repo root for
   `index.html` / `widget.html`) and to `data/current.json`.
6. Append a dated snapshot to `data/history/<observation_date>.json`.

## Manual mode (for now)

Until the launcher is automated, `weather.json` can be edited or
regenerated by hand, as long as it conforms to the schema above. Set
`"demo": true` while the data is not a live measurement, and drop that
field (or set it `false`) once real observations are wired in.
