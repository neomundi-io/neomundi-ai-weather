NeoMundi AI Weather — Widget Gallery

Toutes les configurations du widget unique weather-widget.html, pilotées par paramètres d'URL — voir intégration_FR.md pour la référence complète de tous les paramètres.
Chaque exemple ci-dessous est une vraie iframe, pas une image statique — ce que tu vois est exactement ce qui s'affichera une fois collé chez toi. Les données affichées sont les données réelles de weather.json.

Section 1 — Widget individuel (1 provider)

Position du logo

Le point coloré (statut) est toujours affiché — le logo est additif, jamais un remplacement. logo_pos= ne change rien tant que logos=true n'est pas activé.
logo_pos=left (défaut)
logo_pos=right
logo_pos=top
logo_pos=bottom
logos=false (référence, sans logo)
Voir les snippets 
<!-- logo à gauche (défaut) -->
